# environment-maintenance 5.1.1

[English](../README.md) | Русский

Подготовьте рабочий каталог приложения, установите объявленные зависимости, проверьте ресурсы и управляйте запущенными процессами через команды, описанные в JSON. Приложение определяет выполняемые действия; `start-app` исполняет декларации и возвращает структурированный результат с кодами выхода и полными потоками.

Инструмент даёт разработчику и автоматизации одинаковые явные команды подготовки и запуска приложения.

## Установка

Требуются Linux, Node.js 22+, npm 10+ и Python 3.11+ с venv и pip. В npm-проекте приложения:

```bash
ENVIRONMENT_MAINTENANCE_PYTHON="$(command -v python3)" \
npm install --save-dev --save-exact --ignore-scripts=false environment-maintenance@5.1.1
```

npm создаёт собственное Python-окружение инструмента. Сохраните зависимость и созданный lock вместе с приложением. [Инструкция установки](installation.md) описывает prerequisites и offline-поставку.

## Быстрый пример

Пример обеспечивает наличие каталога `var` в приложении. Выполните его там же, где установлен пакет:

```bash
cat > em.json <<'JSON'
{
  "operations": {"infra": "infra.json"},
  "interpreters": {
    "exit": {"module": "command_execution.actions.interpreters", "attribute": "exit_result"}
  }
}
JSON
cat > infra.json <<'JSON'
{
  "requirements": [{
    "id": "runtime-dir",
    "commands": [{
      "argv": ["mkdir", "-p", "var"],
      "cwd": ".",
      "env": {},
      "interpreter": {"name": "exit", "options": {"accept": [0]}}
    }]
  }]
}
JSON
printf '{}\n' > parameters.json
./node_modules/.bin/start-app infra --config em.json --parameters parameters.json \
  --base-dir "$PWD" --requirements '["runtime-dir"]'
test -d var && printf 'runtime directory ready\n'
```

Команда возвращает JSON со `status: "succeeded"` и печатает `runtime directory ready`. Каталог создаёт объявленная команда `mkdir`. Операцию можно повторять: `mkdir -p` допускает существующий каталог.

Замените команду действием обслуживания вашего приложения; добавляйте требования с IDs для выбора отдельных ресурсов. [Руководство подготовки ресурсов](resource-preparation.md#подготовка-ресурсов) объясняет проверки, параметры, интерпретаторы и результаты отказа.

## Команды

| Команда | Назначение |
|---|---|
| `start-app infra` | Подготовить объявленную инфраструктуру. |
| `start-app deps` | Подготовить объявленные зависимости приложения. |
| `start-app adjust` | Выполнить объявленное командное или сетевое согласование настроек. |
| `start-app check` | Проверить объявленные условия ресурсов. |
| `start-app run` | Запустить выбранные именованные приложения и сохранить их группы процессов. |
| `start-app stop` | Остановить сохранённые группы процессов приложений. |

Операции вызываются явно. Приложение предоставляет инструменты, параметры, рабочие каталоги и интерпретаторы результата. Реестр именованных запусков находится в выбранном OS temp; `stop` читает сохранённый реестр без текущей конфигурации приложения.
