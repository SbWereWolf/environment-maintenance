# Известные ошибки EM

## Ведение реестра

Здесь перечисляются только активные подтверждённые дефекты EM.
Подробные воспроизведения, решения и полные результаты проверок принадлежат
соответствующей Task. Исправленная активная запись удаляется в той же проверенной
правке; история остаётся в Git и материалах Task.
