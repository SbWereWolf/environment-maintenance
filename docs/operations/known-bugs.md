# Известные ошибки EM

## Ведение реестра

Здесь перечисляются только активные подтверждённые дефекты EM.
Подробные воспроизведения, решения и полные результаты проверок принадлежат
соответствующей Task. Исправленная активная запись удаляется в той же проверенной
правке; история остаётся в Git и материалах Task.

## Активные дефекты

### EM-DOC-001 — неверная зависимость при установке из исходников

Task `EM-BARE-LOCAL-20261115`. Инструкция установки предлагает wheel
`command-execution` 0.1.0, тогда как текущая поставка требует 1.0.0.
До исправления выбирайте `command-execution==1.0.0` согласно `pyproject.toml`.
