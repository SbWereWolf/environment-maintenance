# Установка самостоятельного приложения

[Договор npm-поставки](npm-distribution.md#пакетная-поставка-npm) содержит полную инструкцию установки выбранного экземпляра.

## Npm-поставка

Приложение выбирает конкретный tgz5.0.0 своей npm-зависимостью с package.json, npm-generated lock и собственным installed runtime. Глобальный prefix также поддерживается. Каждое независимое приложение выбирает и обновляет экземпляр отдельно; несколько регистраций одного приложения могут использовать его копию.

## Условия

Linux/POSIX, Node22+, npm10+, абсолютный Python3.11+ с venv/pip и доступ к выбранным build/runtime dependencies. Проверенная среда указана в [README](../README.md#проверки). Writable prefix и индекс либо offline wheelhouse предоставляет владелец установки.

Python и `.venv` пакета принадлежат инструменту. Python/Node/PHP приложения, терминал, display и команды обслуживания принадлежат приложению. Установка пакета не развёртывает внешние ресурсы.

## Установка из исходников

Выберите точные исходники5.0.0 и собственный каталог установки. Из их корня:

```bash
python3 -m venv --copies .venv
.venv/bin/python -m pip install .
./start-app --version
./start-app --help
```

Корневой entry использует соседний установленный Python с `-I`, сохраняя cwd вызывающего приложения. Изменение source требует явной переустановки выбранных байтов владельцем окружения.

## Установка готового wheel

Из подготовленного Python с pip в своём окружении:

```bash
/absolute/path/to/venv/bin/python -m pip install \
  /absolute/path/to/environment_maintenance-5.0.0-py3-none-any.whl
/absolute/path/to/venv/bin/start-app --version
```

Wheel содержит Python API и console entry. Для bundled docs/examples/skill и npm-границы выбирайте [npm-комплект](npm-distribution.md#пошаговая-инструкция).

## Пути и обновление

Permanent source, конфигурации и выбранная supply позволяют восстановить установленную копию после удаления disposable runtime. Единственный исходник нужного системе обработчика хранится в Git/выбранной поставке, а не только в `.runtime` или Task-root. Installed venv воспроизводится package manager.

Согласуйте version/archive/lock/config до обновления. Следуйте [миграции](migration-v5.md#переход-конфигурации): новый формат списков и декларации ресурсов переключаются вместе с зависимостью. Прежние выпуски сохраняют свои байты и документацию. Обновление одного экземпляра не обновляет другие; рабочие конфиги и данные сохраняет их владелец. Проверка кандидата не означает публикацию или внедрение.
