# Сборочные колёса npm-поставки

`wheelhouse.lock.json` фиксирует версии, исходные URL и SHA-256.
Колёса используются для офлайн-сборки EM и не входят в дистрибутив npm.

| Компонент | Лицензия |
| --- | --- |
| setuptools | MIT |
| wheel | MIT |
| packaging | Apache-2.0 или BSD-2-Clause |

Тексты лицензий входят в каталоги `.dist-info` соответствующих колёс.
