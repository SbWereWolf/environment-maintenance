# Пример запуска процессов

[Каноническая инструкция](../../docs/process-launch.md#пошаговая-инструкция)
описывает подготовку рабочих копий, CLI/API, пустую выборку и прямой инструмент.

- `app.example.json` — главный файл с сопоставлением `run` и готового обработчика.
- `run.example.json` — две цепочки для выбранного терминала и стандартного HTTP-сервера.
- `parameters.example.json` — обезличенные значения для заполнения в рабочей копии.
- `start_console.py` — внешний инструмент передачи запуска; его
  [аргументы и результат](../../docs/process-launch.md#внешний-инструмент).

Отслеживаемые шаблоны сохраняются. Материализованный `app.json` читает соседний
`run.json`; рабочие файлы и логи инструкции размещаются в игнорируемом `build`.
Пример относится к исходникам разработки 2.0, а не к переустановке релиза.
